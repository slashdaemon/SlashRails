## SlashRails 0.2.0

SlashRails now runs on every Minecraft version from 1.20.1 to 26.3.

**Where it runs**
- **Fabric** (with Fabric API): every version from 1.20.1 to 26.3.
- **NeoForge**: 1.20.4, and every version from 1.20.6 to 26.3. The 26.3 build is marked beta, like NeoForge 26.3 itself.
- **Forge**: 1.20.1. The same file also runs on NeoForge 1.20.1.

Pick the file for your Minecraft version and loader. As before, install it on the server **and** on every client.

**Good to know**
- On 1.21.2 and later, carts that use Minecraft's experimental "Minecart Improvements" physics ride the vanilla line; the smoothed track is still drawn.
- On NeoForge 26.1 and later, NeoForge no longer lets rails change a passing cart's behaviour, so modded rails in a smoothed run act like plain vanilla ones.
- Nothing else changes: same Track Smoother, same curves, same config.
